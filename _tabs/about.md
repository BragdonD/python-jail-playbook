# Python Jail Playbook

A reusable, educational guide for escaping restricted Python environments
("Python jails" / pyjails).

The posts walk through fingerprinting, capability discovery, object
introspection, code-object inspection, attribute-access and filter bypasses,
traceback/frame escape, and reaching files or a shell. Challenge answers and
flags are deliberately omitted.
